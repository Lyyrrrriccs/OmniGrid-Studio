How to Install & Activate a Pack

  1. Download any .json pack file above.
  2. In OmniGrid Studio, open 🎮 Game Addons and click 📥 Import Pack (.json) under Overlay Design Pack.
  3. Select your preferred pack in the dropdown anytime — all connected OBS overlays update live.
